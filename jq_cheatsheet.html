jq Cheatsheet

Slice, transform, and build JSON from the command line without writing throwaway scripts.

Common Invocation

jq + 'filter'

Filter first, then file/stdin

Core Basics

  • Pretty-print JSON jq . data.json
  • Compact output jq -c '.[]' data.json
  • Raw strings (no quotes) jq -r '.name' data.json
  • Read from stdin cat data.json | jq '.id'
  • Check valid JSON jq empty data.json
  • Sort object keys jq -S . data.json
  • No color output jq -M . data.json

Select & Filter

  • Field access jq '.user.email' file.json
  • Array item jq '.[0]' file.json
  • Array slice jq '.[1:4]' file.json
  • Filter by condition jq '.[] | select(.ok)' file.json
  • Multiple fields jq '.[] | {id,name}' file.json
  • Has key? jq 'has("items")' file.json
  • Safe optional access jq '.meta?.version' file.json

Transform Data

  • Map values jq 'map(.price * 1.1)' file.json
  • Add/update field jq '.status = "done"' file.json
  • Delete field jq 'del(.debug)' file.json
  • Sort array by key jq 'sort_by(.score)' file.json
  • Unique values jq 'unique_by(.id)' file.json
  • Flatten nested arrays jq 'flatten' file.json
  • Group by field jq 'group_by(.team)' file.json

Files & Output

  • Read all files as array jq -s '.' a.json b.json
  • JSONL to JSON array jq -s '.' data.jsonl
  • JSON array to JSONL jq -c '.[]' data.json
  • Null input mode jq -n '{ts: now}'
  • Pass shell arg jq --arg env prod '.env=$env' f.json
  • Pass numeric arg jq --argjson n 3 '.limit=$n' f.json
  • Read raw text lines jq -R . notes.txt
  • Raw lines as one JSON array jq -Rs 'split("\n")[:-1]' notes.txt
  • Exit status for CI checks jq -e '.ok == true' f.json

Typical Use Patterns

1. API Triage Fast

Pull just the signal from noisy API payloads while debugging endpoint responses.

# 1. Hit endpoint

$ curl -s https://api.example.com/users

# 2. Keep only name + active flag

$ ... | jq '.users[] | {name, active}'

# 3. Show only active names

$ ... | jq -r '.users[] | select(.active) | .name'

2. Log Summaries

Convert JSONL logs into compact metrics in one pipeline for incident response.

# 1. Read one JSON object per line

$ cat app.log.jsonl

# 2. Slurp lines to one array

$ ... | jq -s '.'

# 3. Count by level

$ ... | jq 'group_by(.level) | map({level: .[0].level, n: length})'

3. Build JSON for CLI Tools

Generate well-formed request bodies from shell variables without brittle quoting.

# 1. Set shell values

$ user_id=42; role=admin

# 2. Build JSON from null input

$ jq -n --arg id "$user_id" --arg role "$role" '{id: ($id|tonumber), role: $role}'

# 3. Pipe to next command

$ ... | curl -X POST -H 'content-type: application/json' -d @- ...

4. JSONL <-> JSON Array

Switch formats depending on whether tools expect one object per line or one top-level array.

# 1. JSONL to JSON array

$ jq -s '.' events.jsonl > events.json

# 2. JSON array to JSONL

$ jq -c '.[]' events.json > events.jsonl

# 3. Quick row count from JSONL

$ jq -s 'length' events.jsonl

Pro tip: Keep complex jq filters in a file and run jq -f filter.jq data.json for readability and reuse.
