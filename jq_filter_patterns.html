jq Filter Patterns

A pattern-first reference for common jq filters: navigate, select, reshape, aggregate, and compose pipelines quickly.

Starter Form

jq 'filter' input.json

Build from small filters, then pipe them

1. Access & Paths

  • Nested key .user.email
  • Quoted key ."first-name"
  • Array index .[0]
  • Array slice .[1:4]
  • Optional access .meta?.version
  • List keys keys
  • Leaf scalars .. | scalars

2. Select & Match

  • Boolean condition .[] | select(.ok)
  • Equals match select(.env=="prod")
  • Range check select(.age>=18 and .age<65)
  • Regex contains select(.msg | test("error";"i"))
  • Starts/ends with select(.name | startswith("svc-"))
  • Has key select(has("id"))
  • Null-safe default .region // "unknown"

3. Reshape Objects

  • Pick fields {id,name,status}
  • Rename field {user_id:.id, name:.name}
  • Add field . + {ok:true}
  • Update value .count |= (. + 1)
  • Delete field del(.debug, .trace)
  • Merge objects .base * .override
  • To key/value rows to_entries[]

4. Array Patterns

  • Map values map(.price * 1.1)
  • Filter in map style map(select(.active))
  • Sort by key sort_by(.score)
  • Reverse sort sort_by(.score) | reverse
  • Unique by field unique_by(.id)
  • Flatten nested arrays flatten
  • Top N rows sort_by(.score) | reverse | .[:5]

5. Group & Reduce

  • Count items length
  • Sum numbers map(.amount) | add
  • Average value (map(.latency)|add) / length
  • Min/max by field min_by(.ts), max_by(.ts)
  • Group by key group_by(.team)
  • Group + counts group_by(.s) | map({s:.[0].s,n:length})
  • Custom reduce reduce .[] as $x (0; . + $x.cost)

Common Pipeline Recipes

1. Select + Project

Keep only rows you care about, then trim to report columns.

.[]

| select(.status == "open")

| {id, owner, priority}

jq '.[] | select(.status=="open") | {id,owner,priority}'

2. Group + Count

Build a compact distribution table from event streams.

group_by(.level)

| map({level: .[0].level, count: length})

jq 'group_by(.level) | map({level:.[0].level,count:length})'

3. Update In Place

Normalize shape while preserving everything else.

.items |= map(.price |= (. * 100 | floor))

| .currency = "cents"

jq '.items |= map(.price |= (. * 100 | floor)) | .currency="cents"'

4. JSONL Roundtrip

Swap between one-object-per-line and one-array formats.

jq -s '.' events.jsonl > events.json

jq -c '.[]' events.json > events.jsonl

Use -s for slurp, .[] for explode

Pro tip: Start with a tiny filter like .[] | {id} and grow it step-by-step instead of writing a giant one-liner first.
